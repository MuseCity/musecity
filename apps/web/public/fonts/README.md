# Manrope

Self-hosted, unmodified Latin variable webfont (weights 400–800), retrieved 2026-09-22.

- Source: https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&display=swap
- Font: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
- Upstream and license: https://github.com/google/fonts/tree/main/ofl/manrope
- License: SIL Open Font License 1.1; see `manrope-OFL.txt` and `manrope-FONTLOG.txt`.

Other scripts use the platform's system font. No runtime request to Google Fonts is required.
